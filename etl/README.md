# B100 Intelligence - Stock Analytics Dashboard

## Overview

B100 Intelligence is a stock analytics platform developed using Python, Machine Learning, and Power BI.

The project analyzes company financial statements and generates insights based on:

- ROE (Return on Equity)
- ROCE (Return on Capital Employed)
- Net Profit
- EPS
- Financial Ratios
- Machine Learning Score

## Features

### Data Processing

- Extract financial data
- Clean datasets
- Merge multiple sources
- Generate final ML dataset

### Machine Learning

Custom ML score based on:

- ROE
- ROCE
- Net Profit

Classification:

- Strong
- Average
- Weak

### Power BI Dashboard

Pages Included:

1. Dashboard
2. Market Snapshot
3. Sector Analysis
4. Company Analysis
5. Financial Analysis
6. Top Performers

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
